# Charlie's Game Compendium
A simple Python Terminal Based game compendium I made to help sharpen my skills with python!
![Screenshot of the game](https://github.com/CharlieLindsay/charlie-s-game-compendium/blob/main/Screenshot%202026-09-20%20164421.png?raw=true)

## Features
- Three games - Tic Tac Toe, Connect 4, Number Guesser
- Leaderboard storage for all 3
- Primary user name saving
- Explanations on how to play

## How to Play
- Install using pip: pip install charlie-game-compendium
- Run using: charlie-games


This was made during Hackclub's Stardance. I hope you enjoy and like it!
